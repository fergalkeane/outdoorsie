# Outdoorsie photography

Put each photo in an `img/` folder next to `index.html`, saved as JPG with exactly the file name below. Until a file exists, the site shows a tinted landscape placeholder in its place.

Sizes: heroes and banners 2400px wide, cards and region tiles 1200px wide, gallery photos 1600px wide. Compress to roughly 200–400 KB each.
