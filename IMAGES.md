# Outdoorsie photography

Right now every photo loads straight from Unsplash. To switch to your own copies, download each one, save it in `img/` with the file name below, and upload it. The site uses a local file automatically once it exists. If a photo can’t load from either place, a tinted mountain placeholder shows instead.

To swap a photo, change its ID in the `UNSPLASH` list near the top of the script in `index.html` (the part of an Unsplash image address that starts with `photo-`).
